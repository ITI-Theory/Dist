Printable and distributable artefacts. These are not the formal academic
record; formal records and DOI metadata live in `zenodo/`.

## Files

### `ttheory-cheatsheet.pdf`

A one-page mathematical reference card for the Universal Somatic Field.
Contains the master field equation, retarded propagator, somatic memory kernel,
Hopfield energy function, Zoom Operator hierarchy, and Osterwalder–Schrader
reference points.

Use it as a compact working map. It is not a proof certificate: Lean checks
named statements under their definitions and axioms, and the current proof
surface still includes axioms and `sorry`s as documented in U.

**Download:** [`ttheory-cheatsheet.pdf`](https://github.com/ITI-Theory/Dist/blob/main/stuff/ttheory-cheatsheet.pdf)

### Lulu cover-wrap source

The shared XeLaTeX full-wrap renderer lives in
[`U/paper/lulu-cover/`](https://github.com/ITI-Theory/U/tree/main/paper/lulu-cover).
It generates one back-cover/spine/front-cover PDF from the exact custom
template Lulu supplies after the matching interior has been uploaded. Its
geometry is never inferred from paper thickness or a generic spine formula.

`lulu-cover-template/cover-omnibus-v2.tex` is retained as an early front-cover
art proof only; it is not an uploadable Lulu cover wrap.

**Browse:** [`lulu-cover-template/`](https://github.com/ITI-Theory/Dist/tree/main/stuff/lulu-cover-template)
Paired with: [`Dist/lulu/01-omnibus-v2.pdf`](https://github.com/ITI-Theory/Dist/blob/main/lulu/01-omnibus-v2.pdf)
