## Usage

**For NotebookLM:** Upload all PDFs, or upload `01-omnibus-v2.pdf` plus the
papers you want to interrogate. Ask for evidence labels: formal check,
derived-under-assumptions, simulation, interpretation, or open hypothesis.

**For fine-tuning or evaluation experiments:** Treat these as source documents,
not question-answer labels. Pair with [`PROMPTS.md`](../PROMPTS.md) only after
manual review.
