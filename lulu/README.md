All Lulu-designated artefacts use the registry-owned `lulu_page_limit: 800`.
The U release gate rejects an artefact above that limit before promotion.

## How to upload a new version

1. Log in → **My Projects** → find the project → **Revise project**
2. Upload new interior PDF (replace existing)
3. Review print preview → **Save**
4. If cover changed: also upload new cover PDF
5. Note the revision date below in the release log
