# Interactive Artefacts

Static public [T]-Theory artefacts. GitHub Pages publishes this directory only;
PDF distribution, Zenodo files, and print artefacts remain outside the web
deployment.

- `soma-field-operator/`: interactive 11D body map. The visual engine is
  sourced from the pinned U commit and Three.js is loaded from a pinned CDN.
  Treat the display as an interpretive model explorer, not clinical,
  physical, or proof validation.

Current public record counts live in `PAPERS.yaml`: 24 papers (P1–P24),
datasets E1/D1/D2, the paper omnibus, the Fractal Thesis, Vol I/II, and
15 rewritten [T]-Theory books.
